# Security Policy

## Reporting

Do not open public issues for security vulnerabilities.

1. Email security@eezfunnel.dev.
2. Include reproduction steps, impact, suggested fix.
3. Allow 72 hours for response.

## Supported versions

| Version | Supported |
|:--------|:----------|
| 0.1.x   | Yes       |
| < 0.1   | No        |

## In scope

- Injection (HTML, SQL, command, template).
- Authorization bypass (MCP token, admin endpoints).
- Denial of service.
- Data exposure.
- Dependency vulnerabilities.

## Out of scope

- Absence of auth in v0.1.0. By design.
- Deployment misconfigurations.
- Social engineering.
- Physical attacks.

## Disclosure

Security advisory published after fix. Credit given unless anonymous.
