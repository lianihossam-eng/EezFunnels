# Eez Funnel v0.1.0

The first release of Eez Funnel is a self-hosted, single-user funnel builder. Deploy the Worker to your Cloudflare account, then create funnels from the dashboard, the HTTP API, the native CLI, or the MCP endpoint.

## Included

- Five starter blueprints and five theme presets.
- A visual editor for reordering existing sections, editing supported fields, previewing at mobile, tablet, and desktop widths, and saving immutable revisions.
- Publication of a saved revision at `/f/:slug`.
- A native `eez` CLI for listing, creating, and publishing funnels, retrying an uncertain create or publish request, and forwarding `wrangler deploy`.
- A stateless `/mcp` endpoint with Bearer authentication and the documented command and funnel tools.
- A bounded HTTP API with idempotent mutation requests and structured errors.

## CLI downloads and checksum verification

Download `SHA256SUMS` and only the binary for your operating system from this release:

- Linux x86_64: `eez-v0.1.0-linux-x86_64`
- macOS Apple Silicon: `eez-v0.1.0-macos-aarch64`
- Windows x86_64: `eez-v0.1.0-windows-x86_64.exe`

`SHA256SUMS` contains entries for all three binaries. Each command below selects only the checksum entry for the downloaded asset, so the other two binaries do not need to be downloaded.

On Linux x86_64, run this from the directory containing the downloaded binary and checksum file:

```sh
set -o pipefail
grep -F '  eez-v0.1.0-linux-x86_64' SHA256SUMS | sha256sum --check
```

On macOS Apple Silicon, select the macOS entry and verify it with the system `shasum` utility:

```sh
set -o pipefail
grep -F '  eez-v0.1.0-macos-aarch64' SHA256SUMS | shasum -a 256 -c
```

On Windows PowerShell, compare the selected Windows entry with the downloaded executable:

```powershell
$entry = @(Select-String -Path .\SHA256SUMS -Pattern '^([0-9a-fA-F]{64})  eez-v0\.1\.0-windows-x86_64\.exe$')
if ($entry.Count -ne 1) { throw 'Windows checksum entry is missing or duplicated' }
$expected = $entry[0].Matches[0].Groups[1].Value.ToLowerInvariant()
$actual = (Get-FileHash .\eez-v0.1.0-windows-x86_64.exe -Algorithm SHA256).Hash.ToLowerInvariant()
if ($actual -ne $expected) { throw 'Windows binary SHA-256 does not match SHA256SUMS' }
```

## Install the CLI

On Linux x86_64, copy the versioned binary to `~/.local/bin/eez`, set executable permissions, and add that directory to PATH:

```sh
mkdir -p "$HOME/.local/bin"
install -m 0755 ./eez-v0.1.0-linux-x86_64 "$HOME/.local/bin/eez"
touch "$HOME/.profile"
grep -qxF 'export PATH="$HOME/.local/bin:$PATH"' "$HOME/.profile" || printf '%s\n' 'export PATH="$HOME/.local/bin:$PATH"' >> "$HOME/.profile"
export PATH="$HOME/.local/bin:$PATH"
eez --help
```

On macOS Apple Silicon, install the matching binary the same way and persist PATH in the default Zsh login profile:

```sh
mkdir -p "$HOME/.local/bin"
install -m 0755 ./eez-v0.1.0-macos-aarch64 "$HOME/.local/bin/eez"
touch "$HOME/.zprofile"
grep -qxF 'export PATH="$HOME/.local/bin:$PATH"' "$HOME/.zprofile" || printf '%s\n' 'export PATH="$HOME/.local/bin:$PATH"' >> "$HOME/.zprofile"
export PATH="$HOME/.local/bin:$PATH"
eez --help
```

On Windows PowerShell, copy the `.exe` to a user `bin` directory and add that directory to the persistent user PATH and current session:

```powershell
$installDir = Join-Path $HOME 'bin'
New-Item -ItemType Directory -Force -Path $installDir | Out-Null
Copy-Item .\eez-v0.1.0-windows-x86_64.exe (Join-Path $installDir 'eez.exe')
$userPath = [Environment]::GetEnvironmentVariable('Path', 'User')
if (($userPath -split ';') -notcontains $installDir) {
    $updatedPath = if ([string]::IsNullOrWhiteSpace($userPath)) { $installDir } else { "$installDir;$userPath" }
    [Environment]::SetEnvironmentVariable('Path', $updatedPath, 'User')
}
$env:Path = "$installDir;$env:Path"
eez.exe --help
```

The PATH changes apply to the current shell; the profile or user PATH update also applies to later sessions.

Configure the CLI with the HTTPS URL of your deployed Worker before using remote commands:

```sh
eez config set endpoint https://<your-worker-url>
eez funnels list
```

See the [deployment guide](https://github.com/lianihossam-eng/EezFunnels/blob/main/docs/deploy.md), [CLI reference](https://github.com/lianihossam-eng/EezFunnels/blob/main/docs/commands.md#native-cli), and [security guide](https://github.com/lianihossam-eng/EezFunnels/blob/main/docs/security.md) for setup and usage details.

## Scope and limitations

This release is single-user and does not include account authentication, multi-user roles, custom subdomains, CRM, analytics, email, image uploads, or funnel JSON import/export. Cloudflare resources are created and billed under the operator's account. Review the security guide before exposing an instance publicly.
